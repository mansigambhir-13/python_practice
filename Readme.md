## 🛠️ Technologies Used

- Python 3
- Standard Library (`random`, `datetime`, `os`, etc.)

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/mansigambhir-13/python projects.git
   cd DSA
````

2. Install dependencies (for projects that require them):

   ```bash
   pip install -r requirements.txt
   ```

3. Run any script:

   ```bash
   python Dicerollingsimulator.py
   ```
